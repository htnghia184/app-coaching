## Import policy
1. Open the original Word file and preserve all text, prompts, options, keys, explanations, rubrics, sequencing and step timing exactly.
2. Do not infer full content from the engineering summary table.
3. Record source file ID/revision, imported content version and reviewer before publication.
4. If Codex cannot access SharePoint, obtain source files via an authorized local download or approved asset sync; do not fabricate missing content.
5. Avoid storing learner recordings or personal data in GitHub.
6. Changes to teaching content must originate in SharePoint, be reviewed and produce a new content version; preserve old attempt version references.
