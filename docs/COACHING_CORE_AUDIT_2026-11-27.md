## Shared contract for parallel workstreams

Use four provisional Speaking LO IDs, one per existing content package: REE, Natural Opening, Self-Questioning, Example. Academic owner approves exact wording and criteria against SharePoint. LO catalog and version remain independent of module versions. A task may reference a module and an LO separately; a module may support an LO without being the sole path. Evidence references a task submission/revision, versioned module attempt, or manually documented live session. Evidence is not itself an assessment. Coach assessment references one or more evidence records, records status, rationale, reviewer and time, and never follows automatically from module completion. Keep historical assessments append-only. Record time spent reviewing and planning from the first pilot as coach-entered minutes; show evidence-backed learner progress without inferring IELTS band.

The synthetic prototype exercises two learners with one IELTS target, different LO priorities, module and direct-task paths, and a live-session note. It has no persistence or microphone/network call. The proposed SQL in `docs/proposed/coaching_core_lo_review_only.sql` is a review artifact; confirm exact live constraints, authenticated role behavior and module attempt schema in an isolated environment before adoption.
